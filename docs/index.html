Erişim yok

Modül ana ekranda görünmez, verileri okunamaz.

Gözlemci

Kayıtları görür, değişiklik yapamaz. Dış işte rapor alabilir.

Kullanıcı

Günlük işini yapar: geri bildirim, mesaj, kendi işinin oranı; dış iş açma, çıkış–giriş.

Düzenleyici

Modüldeki tüm kayıtları ekler, düzenler, siler; ayarları değiştirir.

Yönetici

Sistem rolü: tüm modüllerde tam yetki ve bu ekrana erişim.

Yeni kişi eklerken

  • E-posta ile girecekse önce Firebase Console → Authentication → Users → Add user ile hesabını açın, sonra buraya ekleyin.
  • Google hesabıyla girecekse yalnızca Gmail adresini buraya yazmanız yeterli.
  • Ad Soyad, Proje Takip'teki "Sorumlu" adıyla aynı olmalı; kişi kendi işlerini bu eşleşmeyle tanır.
  • Yetki değişikliği kaydedilince kişinin ekranı anında güncellenir.

Kayıtları içe aktar

Önceki takip ekranından alınan karmen-veri.json dosyasını Proje Takip'e aktarır. Aynı numaralı kayıtların üzerine yazılır.
